# 品图 v0.3.0：独立部署的电商视觉工作台

本版整理为通用开源项目：默认使用服务器 Pi / Codex CLI，也可配置兼容 Responses 与 Images 的服务，不需要接入私有账号或云端额度平台。

主要更新：

- 商品分析后问答，支持 PDF、Word 等资料及图片参考。
- 详情页整套策略、逐屏脚本、统一设计规范与材质细节覆盖；确认前可只改写提示词。
- 持久化图片任务、单张重试和精修，重复请求与重启不会自动重复派发。
- 内网口令、浏览器作品隔离、本机意见反馈、更新案例及 Logo 动画。
- 重新整理安装、安全、接口和部署文档，固定提交构建源码包及 SHA-256 校验和。

需要 Node.js 22.19+；安装依赖使用 `npm ci`。下载源码 ZIP 或 tar.gz，复制 `.env.example` 后按 README 配置后台模型。源码包不含依赖、模型、用户数据、登录资料或密钥。现有私有部署请独立安装本版，不要直接覆盖原账本。

验证状态以 [发布报告](RELEASE-REPORT.md) 为准。模拟测试不能代替真实模型验收；本发布准备过程默认不调用真实模型。成图内容仍需人工复核。
