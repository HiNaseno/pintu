## 依赖审查（2026-10-22）

已执行非强制 `npm audit fix`，并将 sharp 升级至 0.35.5；express 5.2.1 / proxy-addr 2.0.8、multer 2.5.0 已消除本轮 high / critical。sharp 的 Node 要求为 >=20.9.0，与本项目 >=22.19.0 相容。相关文档解析、截图处理和图片引用测试 16/16 通过。

`npm audit` 当前仍报告 3 条 moderate，均来自同一传递链：mammoth 1.13.0 → argparse 1.0.10 → sprintf-js 1.0.3，见 [上游公告](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)。argparse 仅由 mammoth 的命令行入口加载；本项目使用解析库入口，实测载入 mammoth 后 require 缓存没有 argparse 或 sprintf-js。未采用 audit 建议的大幅倒退 mammoth，也未强制不兼容的 argparse override。残余告警需继续跟进上游；此结论不等于没有其他依赖风险。

## 浏览器与恢复验收

使用独立运行目录、停用引擎及空 API 凭据，Chromium 验证桌面 1440×1000、手机 390×844 的首页、工作台及案例页。六页均未发现脚本异常、失败资源、破图或横向溢出。反馈真实写入本机测试存储，工作台草稿可刷新恢复，两个浏览器具有不同作品归属。

配置访问口令后验证解锁、刷新后继续授权、owner 不变、HttpOnly Cookie，以及口令不进入 URL、localStorage 或 sessionStorage。口令模式浏览器使用 localhost 测试 Origin；自定义 DNS 未列为通过项。HTTP 集成另覆盖内网 Host、Origin、CSRF、未授权读取和口令轮换。测试服务均已退出，生产目录、生产数据及现有两个服务未变更。

新增恢复案例包括：已完成原图及精修图丢失后从原账本结果重建，保留版本历史且不调用模型；两处图片同时缺失时提示结果不可用并阻止重新生图；重试快照已保存但尚未派发即崩溃时，重启不执行，用户重放原请求才继续同一个已证明未派发的动作。并发容量拒绝明确标为未开始，不错误进入永久待核对。
